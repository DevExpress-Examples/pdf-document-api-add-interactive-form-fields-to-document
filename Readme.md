# PDF Document API - Add Interactive Form Fields to a Document

This example shows how to create interactive form fields (text box and radio button group fields) and add them to an existing PDF document.

>[!IMPORTANT]
> You need a license for the **DevExpress Office File API Subscription** or **DevExpress Universal Subscription** to use this example in production code.
